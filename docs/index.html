Zero-Leak Architecture

Bank-Grade AES-256-GCM
Encrypted Database at Rest

Student privacy and financial audits cannot be compromised. The local database is stored strictly inside encrypted .db.enc containers using authenticated AES-256-GCM.

Machine-Derived Cryptographic Keys

Keys are bound to the hardware entropy and DPAPI profile of the school's authorized computer, preventing unauthorized copying of raw databases to flash drives.

Decrypted Backup & Restore Center

Superadmins can export decrypted standard SQL dumps on-demand for offline archives, tax audits, or backups, secured by password authentication.

Pure Go Embedded SQLite

Powered by ModernC pure Go SQLite engine in WAL mode with a dedicated single-writer pool, eliminating CGO crashes and locked database exceptions.
